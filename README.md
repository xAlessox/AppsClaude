# Apps de sonidos

Apps web sencillas, de un solo archivo cada una. No usan archivos de audio:
todos los sonidos se generan en el navegador con la Web Audio API.

| App | Qué hace | Link |
|---|---|---|
| 🌙 Duerme Bebé | Ruido blanco y canciones de cuna | https://xalessox.github.io/AppsClaude/app-bebe/ |
| 💀 Noche de Terror | 16 sonidos de terror para Halloween | https://xalessox.github.io/AppsClaude/app-terror/ |

Portada con las dos: https://xalessox.github.io/AppsClaude/

Se publican con GitHub Pages ("Deploy from a branch", rama `main`, carpeta raíz):
cada cambio que se sube a `main` se publica solo en 1 o 2 minutos.
